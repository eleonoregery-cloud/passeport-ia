# Passeport IA

Simulateur d'audit déclaratif AI Act pour entreprises françaises, composé d'un client React et d'une API Node.js/Express.

## Démarrage

```bash
npm install
npm run dev
```

Le client est servi par Vite et l'API est disponible sur le port 3001.

Le résultat est indicatif : il ne constitue pas une certification de conformité ni un avis juridique.
